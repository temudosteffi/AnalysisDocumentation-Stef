Class Overview

Q.ServiceComponents.Capitation.cBuildCapEnrolls is the “build” stage for an Advanced Capitation run: it parses an incoming capitation XML message, generates capitation message-queue work (global or PCP) by executing stored-procedure-backed query classes, creates a capitation payment record, and then dispatches batch processing requests (synchronously for single batches or via a proxy for multiple batches). It also loads supporting data (program caps, open payments, global contract data, global affiliation) into the XML message that is passed to downstream batch processors. C

--Created by Kevin Harbauer 2.0 cap service pack
