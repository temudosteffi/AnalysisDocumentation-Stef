Capitation UI Files

Repository: mms-cms-v360-main  |  UX layer: components/ux/Molina.VUE360.Web

What "Capitation" means here: Capitation is a payment model where providers are paid a fixed per-member amount (per member per month) rather than per service. VUE360 has two capitation areas: Provider Capitation Adjustments (adjusting payments for a provider) and Contract Capitation Configuration (defining the capitation rate structure on a contract).

Views (the actual screens)

_CapitationPV.cshtml Provider

Views/ProviderSummary/_CapitationPV.cshtml The Provider → Summary → Capitation Adjustments search screen. Lets users search a provider's capitation adjustments by program, reason, adjustment type, processing date range, and member ID. Enforces roles (Provider_View_Capitation_Adjustments to view, Provider_Modify_Capitation_Adjustments to add/edit/delete) and renders a grid with Edit/Delete row commands.

_AddEditCapitationAdjustmentPV.cshtml Provider

Views/ProviderSummary/_AddEditCapitationAdjustmentPV.cshtml The Add/Edit Capitation Adjustment form. Used to create or modify a single adjustment — selecting Fund, Program, Reason, and Adjustment Type (e.g., MONETARY vs. non-monetary). The form title and save button switch between "Add/SAVE" and "Edit/UPDATE" based on mode.

_CapitationPV.cshtml Contract

Views/ConfigurationPricing/_CapitationPV.cshtml The Contract capitation configuration (read-only display) screen. Shows how capitation is set up on a contract: Capitation Table, Type, Payment Fund, Provider Membership Only flag, Effective date, and Management Capitation indicator. This is the rate-structure definition side, backed by cap factors/terms/pools.

Client-side scripts

CapitationAdjustment.js Provider

wwwroot/js/CapitationAdjustment.js Front-end logic for the provider adjustment screens — driving the search grid, add/edit/delete actions, dropdown filtering, and validation for _CapitationPV and the Add/Edit form.

_CapitationPV.js Contract

wwwroot/js/ConfigurationPricing/_CapitationPV.js Front-end logic for the contract capitation configuration view — loading and displaying capitation factors and terms.

Controllers (server actions behind the screens)

ProviderSummaryController.cs Provider

Controllers/ProviderSummaryController.cs Serves the provider adjustment UI: _CapitationPV (renders the screen), GetProviderCapitationAdjustmentDetails (search with filtering by program/reason/type/date/member), and GetCapitationDropDownData (populates the search dropdowns). Uses caching keyed per provider.

ConfigurationPricingController.cs Contract

Controllers/ConfigurationPricingController.cs Serves the contract capitation config UI: _CapitationPV (contract capitation details), CapitationFactors_Read (cap factor grid), and CapitationTerms_Read (cap terms, including member tier/coverage code enrichment).

LookupController.cs Shared

Controllers/LookupController.cs Provides GetProvAffiliationsForCapAdjustment — a lookup of provider affiliations used when creating a capitation adjustment.

Backing models (data shapes bound to the UI)

Model Purpose
ProviderCapitationAdjustmentModel.cs One capitation adjustment row: adjustment type/status/reason, amount, provider, member, fund, program, capitation rate, member months, recon data, etc. Drives the search grid and add/edit form.
ProviderPaymentCapDetailModel.cs Provider payment capitation detail line items.
ContractCapitationModel.cs Contract-level capitation header: cap type, description, payment fund, effective/terminate dates, PCP-only and management-cap flags. Drives the config display screen.
ContractCapitationFactorsModel.cs Capitation factors (rate multipliers/adjustments) for a contract.
ContractCapTermsModel.cs Capitation terms, including member tier and coverage code.
ContractCapTermPoolsModel.cs Term pools grouping capitation terms.
In short
  • Provider side: search, add, edit, and delete per-provider capitation payment adjustments (_CapitationPV, _AddEditCapitationAdjustmentPV, CapitationAdjustment.js, ProviderSummaryController, ProviderCapitationAdjustmentModel).
  • Contract side: view how capitation rates are configured on a contract — factors, terms, and pools (ConfigurationPricing/_CapitationPV, its .js, ConfigurationPricingController, and the ContractCap* models).
