Class Overview

Q.ServiceComponents.Capitation.cBuildCapEnrolls is the “build” stage for an Advanced Capitation run: it parses an incoming capitation XML message, generates capitation message-queue work (global or PCP) by executing stored-procedure-backed query classes, creates a capitation payment record, and then dispatches batch processing requests (synchronously for single batches or via a proxy for multiple batches). It also loads supporting data (program caps, open payments, global contract data, global affiliation) into the XML message that is passed to downstream batch processors. C

Private Function BuildCapEnrolls() As Boolean

Step-by-step logic (orchestrator) C

  1. Reads a session option qmxGlobals.QCSOptions.optCAPBatchSize into Opt_CAPBatchSize, and if > 0 maps it through qmxGlobals.dictCAPBatch into reqCAPSize. C
  2. If m_XMLMessage.isSummary = True and m_XMLMessage.isGlobal = True, then forces:
    • m_XMLMessage.recondate = m_XMLMessage.capdate
    • m_XMLMessage.reviewdate = m_XMLMessage.capdate
    This ensures summary runs only process the cap month and do not reconcile earlier months. C
  3. Calls LoadProgramcaps() to load program cap configuration for the run. C
  4. If m_programCaps is not Nothing and m_programCaps.Count > 0, iterates rows (via MoveFirst() and While m_programCaps.CurrentRow < m_programCaps.RecordCount) looking for the first programcap row where:
    • effdate <= m_XMLMessage.capdate and
    • termdate >= m_XMLMessage.capdate
    If that row has usetruecap = "Y", then sets m_XMLMessage.capdate = LastDayofMonth(m_XMLMessage.capdate) (i.e., adjusts capdate to month-end). Exits the loop after the first effective row match. C
  5. Calls LoadOpenPayments() to load existing open/paid payments for the provider/program/date window (used later to avoid rebuilding months already paid/open). C
  6. Branches on global vs PCP:
    • If m_XMLMessage.isGlobal = True then calls Build_Global_Enrollments(). C
    • Else calls Build_PCP_Enrollments(). C
  7. Calls ValidateCapFactorProgramFundsForAffiliations() (comment indicates validation for invalid fund configuration for capfactors). C
  8. Calls ProcessEnrollments() to perform downstream enrollment processing and message generation. C
  9. If lDetailId <> "" and m_loginfo is true, writes a process-log detail state: StateStageEnum.ACCEPTED with message "BUILDCAPENROLLS Service Finished provider: " + m_XMLMessage.affiliateid. C
  10. Sets BuildCapEnrolls = True and returns success. C
  11. On exception: traces error, sets BuildCapEnrolls = False, and if lDetailId <> "" writes a process-log detail state with StateStageEnum.ERROR and message: "Provider " + m_XMLMessage.affiliateid + " error - qmxAdvCap.cBuildCapEnrolls.BuildCapEnrolls:: " & ex.Message, then rethrows. C

2) LoadOpenPayments()
